# トラブルシューティング

症状から原因と直し方を引く。パッケージは、描けないもの・見つからないものを黙って読み替えず、インポートかロードで止めて文面で名指す
（README §2.1）。まず Console の赤い文面を読む。

## 1. インポート

| 症状 | 原因 | 直し方 |
|---|---|---|
| Console に赤い誤りが出て、フォントアセットが作られない | ベイク仕様・元フォント・字・グリフ表現の設定の誤り | 文面の頭にベイク仕様のパス（とベイク仕様の行番号）が付く。文面ごとの直し方は [ベイク仕様の書き方](../architecture/04-bake-spec.html) §8 |
| `.t2font` が Project ウィンドウでフォントアセットにならない（▶ が無い） | 拡張子が `.t2font.txt` になっている。または Auto Refresh が無効 | 拡張子を表示して直す。Auto Refresh が無効なら Assets > Refresh |
| 「グリフ表現のベイカーを集められません」 | 同じ種類のベイカーが 2 つある、またはベイカーに引数の無い公開の構築子が無い（README §7.4） | グリフ表現のパッケージを二重に入れていないか（git URL とフォルダの写しの両方など）を確かめる。自作のベイカーなら構築子を足す |
| 未知の種類（`"kind"`）の誤り | そのグリフ表現のパッケージが入っていない | `"kind": "rinkaku"` なら Rinkaku のパッケージを入れる |
| インポートに数十秒かかる | 和文の本文の文字セット（`DevelopmentDefault` など）は字が多い | 想定どおり。結果は Library に残り、ベイク仕様と元フォントを変えない限りやり直さない |
| パッケージを新しい版にしたら、全部のフォントが再インポートされた | ジェネレーターのバージョンが上がった（同じ入力から出る生成物が変わる変更・README §7.5） | 想定どおり。種類のバージョンだけが上がったときは、その種類のフォントだけが再インポートされる |

## 2. 字が出ない・字が違う

| 症状 | 原因 | 直し方 |
|---|---|---|
| Console に「`'名前'` に字 X（U+…）がありません。代替グリフで描きます。」 | ベイク仕様の文字セットに無い字を描いた。実行時に組み立てた文字列に多い | ベイク仕様の `characters` か `charsets` に足す。ホストが別のフォントへ振り分けるなら、先に `T2FontAsset.Contains` で確かめる。文面はコードポイントごとに 1 回（再生を始めるたびに数え直す） |
| 何も描かれない（誤りも出ない） | `CanvasRenderer.materialCount` を入れる前に `SetMaterial` した。`SetMesh` の後に Mesh を詰めた。Canvas の下に無い | [ホストの書き方](02-host-guide.md) §6 の順に渡す（`materialCount`→`SetMaterial`→`SetTexture`→`SetColor`→`SetMesh`） |
| 何も描かれず、エッジスタイルの誤りが出る | エッジスタイルの値が範囲の外か、グリフ表現が描けない効果を使う（`GlyphMaterialCache.Check`・`Get` が止める・README §6.3） | 値を README §6.1 の範囲に収める。グリフ表現の描ける効果は `GlyphRepresentation.Effects` |
| 「フォント '名前' にグリフ表現がありません。再インポートしてください。」 | フォントアセットが壊れている（インポートの途中で止まったなど） | ベイク仕様を右クリックして Reimport |
| フォントの参照が null | インポートが失敗している | Console のインポートの誤りを直す（1 の表） |

## 3. 見た目

| 症状 | 原因 | 直し方 |
|---|---|---|
| 縁取り・ぼかしが、字の周りで平らに断ち切られる | 幾何の範囲が足りない。エッジスタイルか表示サイズを変えた後に幾何を書き直していない（README §4.3） | `GlyphEdgeStyle.QuadExtentEm(表示 px)` を求め直して `WriteGeometry` し直す。0.5 倍より小さく縮める演出は、縮めた後の表示サイズで求める |
| 大きく表示すると角が丸い | SDF の性質（アトラスの 1 texel が表示で数画素になる） | 大きな字は Rinkaku でベイクする（[グリフ表現の選び方](03-choosing-representation.md)）か、SDF の `emPx` を上げる |
| 14px より小さい字がぼける・欠ける | サポートする最小の表示サイズは 14px（README §4.3・§9） | 14px 以上で使う |
| 面の色が `Image` などより明るい | 自作のシェーダが、Canvas の Vertex Color Always in Gamma Color Space を扱っていない（README §5 S9） | 同梱のシェーダは扱う。グリフ表現を自作するなら S9 のとおりに直す |
| 透明にクリアした RenderTexture へ描くと、下の層が透ける | 自作のシェーダの Blend が違う（README §5 S6） | `Blend SrcAlpha OneMinusSrcAlpha, One OneMinusSrcAlpha` にする |
| `RectMask2D`・`Mask` で字が切れない | どちらも `Graphic` に働く部品で、ホストが直接持つ `CanvasRenderer` には効かない | ホストが `CanvasRenderer.EnableRectClipping` に矩形を渡す（[ホストの書き方](02-host-guide.md) §6）。ステンシルのマスクはシェーダに無い |

## 4. 性能

| 症状 | 原因 | 直し方 |
|---|---|---|
| 描画の呼び出し（バッチ）が多い | ホストごとに `GlyphMaterialCache` を持っている（同じ設定でも別のマテリアルになる）。エッジスタイル・フォント（ページ）が字ごとに混ざる。字の間に別の UI が挟まる | キャッシュを 1 つにして共有する。同じフォントとエッジスタイルの字を続けて置く（README §4.4） |
| 字を出したフレームでヒッチが起きる | 描画の途中で初めてマテリアルを作っている | フォントを読んだ時点で `GlyphMaterialCache.Prewarm` する（README §4.5） |
| Rinkaku の描画が重い | 画素あたりの費用が SDF より大きい | 字の多い本文は SDF にする。`indexEm` を上げると速くなる（データは増える・[グリフ表現の選び方](03-choosing-representation.md) §3） |

## 5. 環境

| 症状 | 原因 | 直し方 |
|---|---|---|
| Rinkaku の字だけが、ある機種で描かれない・色が崩れる | シェーダモデル 3.5 に届かない環境 | その環境では SDF のフォントアセットを使う（[グリフ表現の選び方](03-choosing-representation.md) §4） |
| ターゲットをモバイルなどへ切り替えると、`format` が `BC4` のフォントのインポートが失敗する | `BC4` はデスクトップ向けのターゲットだけ（README §9） | そのターゲットでは `R8` でベイクする |
| 外部の NUnit からパッケージのソースをリンクできない | git URL で入れたパッケージは Library の中に置かれる（README §11） | パッケージのフォルダを `Packages/` へ写して使う |
