# 用語（訳語の表）

コード内コメント・例外とログの文面・文書・パッケージの README で使う日本語の用語の正典（D-TERMS）。
**一般的でない訳語（造語・漢語への言い換え）を避け、カタカナ英語か、カタカナ英語＋「する」の動名詞を使う**。
型名・メソッド名・JSON のキーなどの英語の識別子は、そのまま書く。

## 言い換えないもの

- 一般に通じる日本語の用語はそのまま使う: 送り幅・ペン原点・縦メトリクス・輪郭・縁取り・面・外延・
  非ゼロ巻き数・距離変換・符号化・適合検査・生成物。
- 「取り込む」「名指す」などが import や指定文字以外の一般の意味（改善を取り込む・文面が名指す）のときは言い換えない。
  同じく、次の一般の意味の語も言い換えない: 表現する・表現できる（安い層で表現できる）、回数と実行の「回」（1 回だけ・テストを回す）、
  幅を持つ細長い部分の「帯」（縁取りの帯）、比喩の「道具」（衝突を解く道具）。

## 適用の範囲

- **対象**: パッケージ（コメント・例外とログの文面・README）、`Assets/` と `Tests/` のコード（テストの名前を含む）、図を作るスクリプト
  （`Tools/docs-figures/`）、生きた文書（`docs/architecture/`・`docs/reference/`・`docs/plans/`・`docs/roadmap.md`）、`CLAUDE.md`・`README.md`。
- **対象外**:
  - 歴史記録（`docs/archive/`）と、公開済みの版の CHANGELOG の記述。当時の語のまま残す。
  - テンプレートが管理するファイル（`docs/guides/template-sync.md` の表）。直すならテンプレート側で直す。
  - 文字データ（`.t2font` の `characters`・JIS X 0208 の表・描画の見本の文字列）。字そのものなので訳語ではない。
- 新しい用語を使い始めたら、この表に行を足してから使う。
