# docs/reference — 書き手の入口

**どう書くか**（データ・スクリプト・設定ファイルの文法と書き方）の正典を置くフォルダ（D-DOCTREE）。
書き手が「何を書くときに、どれを読めばよいか」を下の表で引く。機械生成の網羅表（キーの一覧など）は `docs/generated/` に置き、
ここの各書からは節名で参照する（表を複製しない・D-DOCDUP）。

| 書くもの | 読む文書 |
|---|---|
| コメント・例外とログの文面・文書の用語（訳語） | [`terminology.md`](terminology.md) |

プロジェクトに独自の書式（スクリプト言語・データ定義・カタログ等）が生まれたら、仕様書をここへ足して上の表に 1 行加える。
