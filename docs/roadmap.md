# ロードマップ

TemplateProject の実装計画。本書は **状態別（now / 着手候補 / 小物 / ゲート付き）** で構成する。

- **順序の正典は「now / next / later」と「着手候補」表のみ**。節の物理順は序列を意味しない。例外は「小物」表の「優先」列で、小物どうしの順だけを決める。
- **設計の詳細は `docs/plans/` の各設計文書が正典**。本書は項目を 1〜2 行＋状態＋リンクで扱う（D-DOCDUP）。
- **完了した項目は完了記録へ退避する**（`archive/completed-roadmap.md`・D-CRMONTH）。本書には未着手・進行中だけを残す。過去の設計判断・経緯は `archive/decisions.md`。
- **区画の意味**: 着手候補＝順序付きで必ずやる／小物＝1〜2 時間規模で随時／ゲート付き＝条件が成立しなければ着手しない。
- **着手候補の番号は安定 ID**（一度振ったら再利用しない）。次の新規番号は表の下に書く。
