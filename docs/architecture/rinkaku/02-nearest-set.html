Rinkaku の必要集合の作り方

Rinkaku のベイカーは、グリッドのセルごとに「そのセルの中で最も近くなりうるセグメント」を書く。本書は、その集合を上位集合（必ず足りている大きめの集合）から始めて、サンプリングで本当に要るものだけを集める手順を、数式と図で説明する。あわせて、同じ問題を区間演算による保守的な上位集合で解いた先行研究（Qin の博士論文）と比べ、「保守的」とは何か、何が「保守的すぎる」のかを述べる。

1求めたいもの: 必要集合

シェーダは画素の em 座標から 1 つのセルを引き、そのセルに書かれたセグメントだけを解いて、最も近いものの距離を返す（01 章 §7）。グリフの全セグメントを解いたときと同じ値になるには、セルの中のどの画素についても、その画素で最も近いセグメントがセルの集合に入っていればよい。そこで、セル C について次の集合を考える。

N(C) ＝ { i ｜ C の中のある点 p で di(p) ＝ minj dj(p) }

di(p) は点 p からセグメント i までの距離（符号なし）。N(C) を必要集合と呼ぶ。セルの集合 L が N(C) を含めば（L ⊇ N(C)）、セルの中の全画素で距離は厳密に正しい。N(C) より大きい分は正しさに効かず、シェーダが解く本数（＝時間）とデータ量を増やすだけである。

幾何で言えば、N(C) はセグメントのボロノイ図（01 章の図 6 の右）で、ボロノイ領域がセル C に重なるセグメントの集合である。ボロノイ図を正確に作れれば答えは出るが、2 次ベジエのボロノイ図の境は一般に高い次数の曲線で、正確に作るのは重い。Rinkaku は図を作らずに、次の 2 つの集合で N(C) を挟む。

2上位集合とは

上位集合（superset）は数学の集合の包含の言葉で、「A ⊇ B のとき A は B の上位集合」という意味である。「上位の階層の集合」や「より抽象的な集合」ではない。Rinkaku で上位集合と言うときは、N(C) を必ず含むことが証明できる、大きめの集合を指す。上位集合を書けば正しさは保証されるが、要らないセグメントも混じる。

反対の向きが部分集合（W ⊆ N(C)）で、要らないものは入らないが、要るものを落としうる。Rinkaku が最後に書く集合 W はこちらに当たる。手順の全体は、

  1. 安い計算で上位集合 S⁺ を作り、N(C) の外にあることが確かなセグメントを捨てる（§3）。
  2. S⁺ の中だけで、セルの中の点をサンプリングして最も近いセグメントを集め、W を作る（§5〜§6）。

である。「上位集合からサンプリングで必要集合を作る」とは、1 で候補を安全に絞り、2 で候補の中から本当に使われるものを拾う、という 2 段の意味である。

3Lipschitz で上位集合を作る

点からセグメント（や任意の図形）までの距離 di は 1-Lipschitz である: どの 2 点 p, q でも |di(p) − di(q)| ≤ |p − q|。点を 1 動かしても、図形までの距離は 1 より多くは変わらない（三角不等式からすぐ出る）。dmin(p) ＝ minj dj(p) も 1-Lipschitz である。

セルの中心を c、対角の半分を h（indexEm 16 で h ＝ √2/32 ≈ 0.0442em）とすると、セルの中のどの点 p も |p − c| ≤ h なので、

di(p) ≥ di(c) − h　　かつ　　dmin(p) ≤ dmin(c) + h

が成り立つ。i が p で最も近いなら di(p) ≤ dmin(p) なので、2 つを繋いで di(c) − h ≤ dmin(c) + h。対偶を取ると、

di(c) > dmin(c) + 2h（＝ dmin(c) ＋ 対角）　⇒　i ∉ N(C)

よって S⁺(C) ＝ { i ｜ di(c) ≤ dmin(c) + 対角 } は N(C) の上位集合で、これが README §4.3 の 1 の「最小＋セルの対角の長さを超えるセグメントを外す」である。測るのはセルの中心 1 点での距離だけで、セグメントの本数ぶんの距離を 1 回ずつ解けば済む。幾何で言えば、S⁺ は「中心 c・半径 dmin(c) + 対角の円に入るセグメント」である（図 3 の橙の円）。

ベイカーはさらに、制御点の AABB までの距離（セグメントまでの距離の下限）が明らかに大きいセグメントを、厳密な距離を解かずに外す。2 次ベジエは 3 つの制御点の凸包に収まるので、その AABB までの距離はセグメントまでの距離を超えない。これは結果の集合を変えず、ベイクの時間だけを縮める。

4上位集合をそのまま書かない理由

S⁺ を書けば正しさは保証される。書かないのは、S⁺ が N(C) よりかなり大きいからである。

  • 余白の幅がセルの大きさで決まる: S⁺ は「最も近い距離 + 対角」の殻に入るものを全部取る。殻の厚さは一定（indexEm 16 で約 0.088em）で、画の幅がそれより狭いと、画の向こう側の縁もいつも殻に入る。CJK の字は画が細く密なので、ここが効く。また、殻の周の長さは半径とともに伸びるので、インクから遠いセルほど多くのセグメントを拾う。
  • 角の外側の楔: 角の頂点が最も近くなる楔の領域（01 章 §7.4）では、頂点を共有する 2 本のセグメントへの距離が等しい（どちらも頂点までの距離）。N(C) の定義では両方が入るが、どちらを解いても距離も符号も同じなので、1 本書けば足りる。サンプリングでは同じ距離なら番号の小さい方を選ぶので、自然に 1 本になる。

上位集合をそのまま書くと、シェーダが解く本数は 2.5〜3.5 倍になる。シェーダはセルのセグメントを全部解くので（01 章 §7.2）、増えた本数の分だけ画素ごとの計算が増える。上位集合が 1 本で済むセルはほとんど無く、ほぼ全部のセルでサンプリングに進む。

5サンプリングで内側から集める

S⁺ が 2 本以上のセルでは、次の 2 つを集めて W にする（README §4.3 の 2）。

  1. セルの中を通るセグメント: その上の点では距離 0 で、必ず最も近い。サンプルの間をかすめるだけのセグメントも、ここで漏れなく入る。字の縁（0 の等値線）の上の画素は、そこを通るセグメントが必ず書かれているので、距離 0 を厳密に返す。
  2. サンプルの最近傍: セルの閉じた面積（角と辺を含む）を 7×7 の格子点でサンプリングし、各点で S⁺ の中から最も近いセグメント（同じ距離なら番号の小さい方）を求める。

ここで S⁺ が効く。セルの中のどの点でも、真の最近傍は S⁺ に入っている（§3）。だから、サンプル点での最近傍を S⁺ の中だけで探しても、全セグメントで探したときと同じ答えになり、解く距離の数は S⁺ の本数で済む。

集めたものはどれも、セルの中のある点（サンプル点か、セグメントが通る点）で実際に最も近いので、W ⊆ N(C)——要らないセグメントは 1 本も入らない。正しさの問題は、要るものを落とすことだけになる（§7）。

62 分で境を詰める

隣り合う 2 つのサンプル a, b で最近傍が違う（i と j）とき、その間のどこかに境がある。境の近くに、どちらのサンプルにも当たらない 3 本目 k の細い領域が挟まっていることがあるので、a–b の中点 m で最近傍を求め、両側へ 2 分して下る（最大 4 段・サンプルの間隔の 1/16 まで）。

ただし、毎回下ると重いので、3 本目が最も近くなりうると Lipschitz で言えるときだけ下る。長さ ℓ の区間の中の点 x は |x − m| ≤ ℓ/2 なので、

dk(x) ≥ dk(m) − ℓ/2　　かつ　　dmin(x) ≤ dmin(m) + ℓ/2

よって k がこの区間のどこかで最も近いには dk(m) ≤ dmin(m) + ℓ が要る。a・b・m の最近傍以外の候補で、これを満たすものが無ければ、その区間を下っても新しいセグメントは出ないので止める（NearestIndex.Bisect）。§3 と同じ論法を、セルの代わりに区間へ当てたものである。

2 分は「隣り合うサンプルで最近傍が違う」所だけで起きる。両端のサンプルの最近傍が同じなら、その間に別のセグメントの細い領域が横切っていても 2 分は起きない（§7 の図 5）。

7取りこぼしと誤差の上界

W が落としうるのは、セルを通らず、サンプル点を 1 つも含まず、2 分でも当たらない小さな、または細い領域でだけ最も近くなるセグメントである。そういう領域の中の点 p で、シェーダは真の最近傍 k の代わりに、W の中で最も近いものを使うので、距離を大きめに返す。その誤差には上界がある。

p に最も近いサンプル点を q、q での最近傍を j とする。j ∈ W（§5）なので、シェーダが返す距離 D(p) は dj(p) 以下で、

d(p) ≤ D(p) ≤ dj(p) ≤ dj(q) + |p − q| ＝ d(q) + |p − q| ≤ d(p) + 2|p − q|

（d ＝ dmin は全セグメントでの真の距離。2 つ目と 4 つ目の不等号が Lipschitz）。よって誤差 D(p) − d(p) は「最も近いサンプル点までの距離の 2 倍」以下である。サンプルの間隔 s ＝ 1/96em に対し、セルの中のどの点も最も近いサンプル点まで s·√2/2 以内なので、最悪でも

D(p) − d(p) ≤ √2·s ≈ 0.0147 em

に収まる（README §8 の「細い取りこぼし」）。これは最悪の場合の上界で、実際に取りこぼしが起きた例は見つかっていない: 24×24 の密なサンプルでセルの集合の最小と全セグメントの最小を比べた検査（RK-8c・ゴシック 13,182 セル・明朝 19,756 セル）で取りこぼしは 0 件だった。上界は距離の大きさについてのもので、字の縁の位置（0 の等値線）は §5 の 1 によって誤差を持たない。

8区間演算の上位集合と「保守的」

論文（papers/rinkaku/）の関連研究の節は、Qin の博士論文について「ラスタ化したボロノイ図が細い領域を取りこぼす問題を区間演算による保守的な上位集合で解いた（著者自身は保守的すぎるとしている）」と書く。この一文を、§1〜§7 の言葉で読み解く。

8.1ラスタ化したボロノイ図の取りこぼし

Qin・McCool・Kaplan（2006）は、グリフの輪郭を線分に近似し、線分のボロノイ図を GPU でラスタ化して、セルごとに「ボロノイ領域がセルに重なる特徴」（＝本書の N(C)）を列挙した。ラスタ化は画素の中心などの点でだけ「どの特徴が最も近いか」を決めるので、点と点の間に収まる細いボロノイ領域は、どの画素にも現れずに落ちる。Rinkaku のサンプリング（§7）と同じ種類の取りこぼしである。

8.2区間演算で上位集合を作る

博士論文（2009）の第 5 章はこれを、点で調べる代わりにセル全体についての範囲で調べて解いた。区間演算は、変数の値を 1 つの数ではなく範囲 [下限, 上限] で持ち、足し算・掛け算などを範囲のまま計算して、結果の範囲を必ず含む範囲を返す計算法である。点 p を「セル C の中のどこか」という範囲で入れると、特徴 i までの距離について

Li ≤ minp∈C di(p)　　かつ　　Ui ≥ maxp∈C di(p)

を満たす下限 Li・上限 Ui が得られる。ある特徴 j について Li > Uj なら、セルのどの点でも di(p) ≥ Li > Uj ≥ dj(p) なので、i はどこでも最も近くならない。そこで

SQ(C) ＝ { i ｜ Li ≤ minj Uj }

を残す。これは N(C) の上位集合で、点を調べないので取りこぼしが原理的に起きない。§3 の S⁺ も同じ形の判定で、Li ＝ di(c) − h・Uj ＝ dj(c) + h という粗い範囲を使ったものに当たる。

8.3何が「保守的すぎる」のか

保守的（conservative）は、計算機科学やグラフィクスで「判断に迷うものは安全な側に倒す」という意味で使う。誤りを「要るものを落とす（偽陰性）」と「要らないものを入れる（偽陽性）」に分けたとき、保守的な方法は偽陰性を 0 と保証し、その代わりに偽陽性を許す。少しでもかかる画素を全部塗る保守的ラスタ化（conservative rasterization）や、物の当たりを大きめの箱で先に調べる判定が同じ考え方である。区間演算の上位集合は、要るかもしれない特徴を 1 本も落とさないので保守的である。

「保守的すぎる」は、偽陽性——N(C) に入らないのに残る特徴——が多すぎる、という意味に読める。残る理由は 2 つある（図 6）。

  1. 判定がセル全体の「最良」と「最悪」を比べる: Li ≤ Uj は、i がいちばん近づく所と j がいちばん遠ざかる所を、別々の点で比べている。たとえば画の向こう側の縁 k は、どの点でも手前の縁 j より画の幅だけ遠く、決して最も近くならない。それでも、画の幅がセルの中での距離の変わり幅（およそ対角）より狭ければ、k の範囲と j の範囲が重なって残る。範囲を正確に求めても、この偽陽性は消えない。
  2. 区間演算の範囲は広がる: 区間演算は、同じ変数が式に何度も現れても、それぞれを独立の範囲として計算する（依存性の問題）。そのため返る範囲は真の範囲より広く、L は小さめ、U は大きめになり、真の範囲なら外せた特徴も残る。2 次ベジエのような曲線への距離では、とくに広がりやすい。

偽陽性の 1 本ごとに、シェーダはそのセルの全画素で余分な距離を 1 回解き、データも 1 本分増える。調査の記録（D-RINKAKU 追記「RK-8a・RK-8b（先行研究の調査）の裁定と細目」）では、著者はこの区間ボロノイ解析を「保守的すぎる」と評し、次の章（2008 年の方式）では使っていない。論文がどれだけ多すぎたかの数値は記録していないが、Rinkaku の見本で同じ考え方の上位集合を測ると規模が分かる。セルを 24×24 の小さな正方形に分け、正方形ごとに Lipschitz の上下限で判定した細かい上位集合（区間演算の代わり）は、取りこぼしの無さを保証する代わりに、セルの平均の本数をゴシックで 1.67 → 2.24、明朝で 2.63 → 3.48 に増やす（約 3 割・RK-8c）。セルを 576 個の小さな正方形に分けて範囲を細かくしても、上位集合で判定する限り（楔で同じ距離になる 2 本を両方残すことも含め）、書く本数は必要な分より目に見えて多くなる。
