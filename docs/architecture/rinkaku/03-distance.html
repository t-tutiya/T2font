Rinkaku の距離の解き方

Rinkaku のシェーダは、画素ごとにセルのセグメントを 1 本ずつ読み、画素からそのセグメントまでの最短距離を求める。曲線（2 次ベジエ）への最短距離は、3 次方程式の根として表せる。シェーダはその根を公式（閉形式）で一度に求め、Newton 法の 1 反復で仕上げる。本書は、この計算を式の導出から順にたどり、単精度の計算で何が起き、Newton 法がそれをどう直すかを実データで示す。

対象の読者
大学の初年度の数学（微分・ベクトルの内積・2 次方程式）を知っている人。3 次方程式の解の公式・3 倍角の公式・Newton 法・浮動小数点は付録で補う

1全体の流れ

画素の位置を P（em）とする。シェーダは画素のセルに書かれたセグメントを順に読み、セグメントごとに「P からの最短距離の二乗」を求めて、いちばん小さいものを残す（01 章 §7）。1 本のセグメントについての手順は次のとおり。

距離そのものではなく距離の二乗を比べるのは、平方根を最後の 1 回（画素の距離を返すとき）だけにするためである。距離が小さい方が二乗も小さいので、比べた結果は同じになる。

22 次ベジエを t の式で書く

セグメントは始点 p₀・制御点 q・終点 p₁ の 3 点で決まる 2 次ベジエ曲線で、パラメータ t（0 ≤ t ≤ 1）の点は

B(t) ＝ (1 − t)² p₀ ＋ 2(1 − t)t q ＋ t² p₁

である（t ＝ 0 で始点、t ＝ 1 で終点）。展開して t の次数でまとめると、

B(t) ＝ p₀ ＋ 2a t ＋ b t²　　ただし　a ＝ q − p₀,　b ＝ p₀ − 2q ＋ p₁

になる。a は始点から制御点へのベクトル、b は曲がり具合（b ＝ 0 なら直線）を表す。微分は

B′(t) ＝ 2a ＋ 2b t（接線の向き）　　B″(t) ＝ 2b（一定）

シェーダのコードは同じ量を次の名前で持つ（c は 2a、d は始点から見た画素の逆向き）。

コード式意味
aq − p₀始点から制御点へ
bp₀ − 2q + p₁B″/2（曲がり）
c2aB′(0)（始点の接線）
dp₀ − P画素から始点へ

画素から曲線の点へのベクトルは e(t) ＝ B(t) − P ＝ d ＋ c t ＋ b t² で、コードの RinkakuDist2 は |e(t)|² を d + (c + b t) t の形（掛け算を減らす Horner の形）で計算する。

ここに来るセグメントは必ず b ≠ 0 である。ベイカーは、ほぼ直線の曲線（|b| < 1/1024 em）を直線にして書き、直線は §12 の別の手順で測る（README §3.2）。§4 で |b|² で割るので、この約束が要る。

3最も近い点の条件

距離の二乗を t の関数として

f(t) ＝ |B(t) − P|² ＝ e(t)·e(t)

と置く。B(t) は t の 2 次式なので、f(t) は t の 4 次式で、t⁴ の係数は |b|² > 0。求めたいのは区間 0 ≤ t ≤ 1 での f の最小値で、最小になる所は

  • 区間の内側で f′(t) ＝ 0 になる所（極小）か、
  • 区間の端（t ＝ 0 か 1）

のどちらかである。内積の微分（付録 A）から

f′(t) ＝ 2 e(t)·e′(t) ＝ 2 (B(t) − P)·B′(t)

なので、f′(t) ＝ 0 は「画素から曲線の点へのベクトルが、その点の接線と直交する」——画素から曲線へ下ろした垂線の足——という条件である。以後、

g(t) ＝ f′(t) / 2 ＝ (B(t) − P)·B′(t)

を使う。g は 3 次式なので、実根（実数の根）は 1 つか 3 つある（付録 B）。f は 4 次で t → ±∞ で +∞ へ行くので、根が 3 つのときは小さい順に極小・極大・極小、1 つのときはそれが極小（f の最小）である。

43 次方程式を作る

e(t) ＝ d ＋ 2a t ＋ b t²、B′(t) ＝ 2a ＋ 2b t を g(t) に入れて展開する（内積は掛け算と同じように分配できる）。

g(t) ＝ (d ＋ 2a t ＋ b t²)·(2a ＋ 2b t)
　　＝ 2 [ (b·b) t³ ＋ 3(a·b) t² ＋ (2 a·a ＋ d·b) t ＋ d·a ]

（t² の項は 2a t·b t と b t²·a から 2(a·b) + (a·b) ＝ 3(a·b)、t の項は 2a t·a と d·b t から。）全体の係数 2 は根に関係しないので落とし、さらに t³ の係数 b·b ＝ |b|²（§2 の約束で 0 でない）で割ると、

t³ ＋ 3kx t² ＋ 3ky t ＋ kz ＝ 0
kx ＝ (a·b) / |b|²　　ky ＝ (2|a|² ＋ d·b) / (3|b|²)　　kz ＝ (d·a) / |b|²

コードでは kk = 1/|b|² を 1 回だけ計算し（割り算は掛け算より重い）、kx・ky・kz はそれを掛けて作る。係数を 3 で割った形にしてあるのは、次の節の式を短くするためである。

52 次の項を消す

3 次方程式の公式は、t² の項が無い形 s³ ＋ 3p s ＋ q ＝ 0 に対して書くのが簡単である。t ＝ s − kx と置いて代入すると（平行移動）、

(s − kx)³ ＋ 3kx(s − kx)² ＋ 3ky(s − kx) ＋ kz
＝ s³ ＋ 3(ky − kx²) s ＋ (2kx³ − 3kxky ＋ kz)

（s² の項は −3kx s² ＋ 3kx s² で消える。これが t² の係数を 3kx にしておいた理由。）よって

s³ ＋ 3p s ＋ q ＝ 0　　p ＝ ky − kx²　　q ＝ kx(2kx² − 3ky) ＋ kz

コードの p・q3 がこの p・q である（q3 は制御点の q と区別するための名前）。根 s が求まれば t ＝ s − kx。

6判別式で枝を分ける

s³ ＋ 3p s ＋ q ＝ 0 の実根の数は、

h ＝ q² ＋ 4p³

の符号で決まる（付録 B）。h > 0 なら実根は 1 つ、h < 0 なら異なる実根が 3 つ、h ＝ 0 なら重根を含む。シェーダは h >= 0.0 で 2 つの枝に分ける。

  • h ≥ 0（§7）: カルダノの公式で、根を立方根で直接書く。
  • h < 0（§8）: カルダノの公式は途中で負の数の平方根（複素数）を通るので使えず、三角関数で書く。

図 2 の点 A が h < 0、点 B が h ≥ 0 に当たる。字の画素では、ほとんどの評価が h ≥ 0 の枝を通る（検査用の 129 字を 128px で描いたとき、曲線の評価の 92.5%）。実根が 3 つになるのは、画素が曲線の凹んだ側で、曲率の中心より奥にあるときだけだからである（t を 0〜1 の外まで延ばした放物線で数える）。

7実根 1 つ: カルダノの公式

根を 2 つの数の和 s ＝ u ＋ v と置く。代入すると

u³ ＋ v³ ＋ 3(uv ＋ p)(u ＋ v) ＋ q ＝ 0

なので、uv ＝ −p となるように u, v を選べば、u³ ＋ v³ ＝ −q だけが残る。u³ と v³ は、和が −q、積が (uv)³ ＝ −p³ の 2 数なので、2 次方程式 z² ＋ q z − p³ ＝ 0 の 2 根である。解の公式から

u³, v³ ＝ ( −q ± √(q² ＋ 4p³) ) / 2 ＝ ( −q ± √h ) / 2

ここで h ≥ 0 なので平方根は実数。u, v はその実数の立方根で、

t ＝ ∛( (√h − q)/2 ) ＋ ∛( (−√h − q)/2 ) − kx

がシェーダの式である（コードの x は 2 つの立方根の中身の組、uv は 2 つの立方根）。

  • HLSL の pow(x, 1/3) は x < 0 で定義されないので、sign(x) * pow(abs(x), 1/3) と書いて負の数の実数の立方根を取る（∛(−8) ＝ −2）。
  • 求めた t は saturate で 0〜1 に丸める。根が範囲の外なら、範囲の中の最小は端にあり（f は根の手前まで単調）、丸めた値がその端になる。

8実根 3 つ: 三角関数の解

h < 0 のときは p < 0 である（q² ≥ 0 なので 4p³ < 0）。z ＝ √(−p) と置き、根を s ＝ 2z cos φ の形で探す。代入して p ＝ −z² を使うと

8z³ cos³φ − 6z³ cos φ ＋ q ＝ 0　⇔　2z³ (4cos³φ − 3cos φ) ＝ −q

3 倍角の公式 4cos³φ − 3cos φ ＝ cos 3φ（付録 C）から、

cos 3φ ＝ −q / (2z³)

h < 0 は q² < −4p³ ＝ 4z⁶、つまり右辺の絶対値が 1 未満であることと同じなので、3φ は acos で取れる。φ₀ ＝ arccos(−q/(2z³)) / 3（0〜π/3）とすると、cos 3φ は周期 2π なので、φ ＝ φ₀, φ₀ ± 2π/3 がどれも解になり、3 つの根は

s₁ ＝ 2z cos φ₀　≥　s₂ ＝ 2z cos(φ₀ − 2π/3)　≥　s₃ ＝ 2z cos(φ₀ ＋ 2π/3)

コードは v ＝ φ₀、m ＝ cos φ₀、n ＝ √3 sin φ₀ として、加法定理から

s₁ ＝ 2z m　　s₃ ＝ 2z(−½ m − (√3/2) sin φ₀) ＝ −z(m ＋ n)

の 2 つだけを計算する（コードの (m + m) * z と (-n - m) * z。acos の引数 q3 / (p * z * 2) は p z ＝ −z³ なので −q/(2z³) と同じ）。真ん中の s₂ は §3 のとおり f の極大なので最小になりえず、計算しない。2 つの極小の t をそれぞれ 0〜1 に丸め、f の小さい方を選ぶ。

9範囲 0〜1 と両端

§7・§8 の後、シェーダは Newton 法で t を仕上げ（§11）、最後に両端の距離 f(0)・f(1) も必ず比べる。同じ近さ（距離で 1e−6 em の幅の中）なら端を選ぶ。これは距離の大きさのためではなく、最も近い点が端か途中かで符号の決め方が変わるからで（端は擬似法線・01 章 §7.4）、閉形式の根の小さな誤差で「端なのに途中」と判定するのを避ける。幅は距離の二乗の差に直して δ(2r ＋ δ)（r は距離・δ ＝ 1e−6）で比べる。

10単精度で起きること

§4〜§8 は数学としては厳密だが、GPU は 32 ビットの浮動小数点（単精度・float）で計算する。単精度の数は有効数字が 2 進で 24 桁（10 進で約 7 桁）しかなく、計算のたびに丸めが入る（付録 E）。多くの場合、閉形式の答えは 1e−7 em ほどの誤差で済むが、ほぼ同じ大きさの 2 数の引き算があると、残る桁が少なくなって誤差が急に大きくなる（桁落ち）。

カルダノの公式にはそういう引き算がある。|p| が |q| に比べて小さいと、h ＝ q² ＋ 4p³ の平方根は |q| にほぼ等しく、(√h − q)/2（q > 0 のとき）は「ほとんど同じ 2 数の差」になる。真の値は −p³/q 程度の小さな数だが、単精度の √h と q はそれぞれ下の桁に丸めの誤差を持つので、差には誤差しか残らない。

10.2全画素での誤差

11Newton 法の 1 反復

閉形式で得た t₀ は、ほとんどの場合ほぼ正しく、まれに §10 の桁落ちで少しずれる。どちらの場合も、t₀ は真の根のすぐ近くにある。根の近くから根へ速く近づく方法が Newton 法（付録 D）で、方程式 g(t) ＝ 0 について

t₁ ＝ t₀ − g(t₀) / g′(t₀)

と更新する。g のグラフに t₀ で接線を引き、その接線が t 軸と交わる所を次の t にする、という意味である（図 4）。

11.1g と g′ を求める

g(t) ＝ e(t)·B′(t)（§3）を、内積の積の微分（付録 A）で微分すると

g′(t) ＝ B′(t)·B′(t) ＋ e(t)·B″(t) ＝ |B′(t)|² ＋ 2 e(t)·b

コードでは e ＝ e(t)、tangent ＝ B′(t) ＝ c + 2 b t、f ＝ g(t)、df ＝ g′(t) である（コードの f・df は本書の g・g′。g ＝ f′/2 なので、本書の f を最小にする Newton 法とも読める）。どれも §2 の a・b・c・d と t から、掛け算と足し算だけで出る。

11.2守りの 2 つの条件

  1. g′(t₀) > 0 のときだけ動く: g′ ＝ f″/2 なので、g′ > 0 は「f がそこで下に凸」＝極小の近くにいる印である。g′ ≤ 0 の所で Newton 法を使うと、極大へ向かったり、接線が水平に近くて遠くへ飛んだりする。そういうときは t₀ のままにする。
  2. 距離が縮んだときだけ採る: 更新した t₁ を 0〜1 に丸め、f(t₁) ＜ f(t₀) なら採り、そうでなければ t₀ のままにする。どんな場合でも、Newton 法で答えが悪くなることは無い。

11.3なぜ 1 反復で足りるか

Newton 法は、根の近くでは誤差が 1 回ごとにおよそ 2 乗になる（2 次収束・付録 D）。根からのずれが ε なら、次は C ε² 程度（C は g″/(2g′) で決まる定数）である。表 1 の評価で t の誤差は

閉形式 6.8×10-3　→　1 反復 1.2×10-5　→（2 反復なら）4.1×10-11

と縮む（t₀ ＝ 0.79359794、t₁ ＝ 0.7867677、t₂ ＝ 0.78678012、真の根 0.78678012・倍精度で計算）。最悪の評価でも 1 反復で t の誤差は 1e−5 ほどになり、最も近い点では f′ ＝ 0 なので、距離への影響はさらに小さい（t のずれの 2 乗に比例する）。表 2 の「Newton の後」の誤差は最大でも 1e−6 em（§9 で端を選ぶ幅と同じ大きさ）で、これより先の反復は単精度の丸めより細かい所を直すだけになる。

11.4なぜ閉形式も要るか

Newton 法だけで解くこともできるが、出発点が要る。f は極小を 2 つ持ちうる（図 2 の点 A）ので、悪い出発点からは、遠い方の極小や極大へ進むことがある。閉形式は全部の極小を候補として出し、f を比べて正しい方を選べる。閉形式で大まかに正しい根を取り、Newton 法で桁を取り戻す、という分担である。

カルダノの公式の桁落ちには、数値計算でよく使う別の手当てもある: 大きい方の立方根 v だけを公式で求め、小さい方は uv ＝ −p から u ＝ −p/v で求める（引き算が消える）。Rinkaku のシェーダはこの形ではなく、Newton 法の 1 反復で仕上げる。Newton 法は桁落ちに限らず、GPU の acos・pow の近似による誤差もまとめて直せる。

12直線は正射影

制御点の差が 0 の項目は直線で（README §3.2）、3 次方程式を解かない。直線 p₀ + t v（v ＝ p₁ − p₀）への垂線の足は、(P − p₀ − t v)·v ＝ 0 から

t ＝ (P − p₀)·v / |v|²

で、これを 0〜1 に丸めた点が最も近い点である（f は t の 2 次式で、極小は 1 つ）。丸めたかどうか（t ≤ 0・≥ 1）で端かを決める。曲線より計算がずっと軽いので、ベイカーはセルのセグメントを曲線を先・直線を後に並べ、GPU の並列の単位（ウェーブ）で曲線の手順を通る回を減らしている（01 章 §5）。

付録

A　ベクトルの内積と微分

2 次元のベクトル u ＝ (ux, uy)、w ＝ (wx, wy) の内積は u·w ＝ uxwx ＋ uywy で、u·u ＝ |u|²（長さの 2 乗）、u·w ＝ 0 は直交を表す。内積は和に分配でき（u·(w ＋ z) ＝ u·w ＋ u·z）、数を外に出せる（u·(k w) ＝ k(u·w)）。

ベクトルが t の関数 u(t), w(t) のとき、成分ごとに積の微分を使うと

d/dt [ u(t)·w(t) ] ＝ u′(t)·w(t) ＋ u(t)·w′(t)

になる（普通の積の微分と同じ形）。とくに d/dt |u(t)|² ＝ 2 u(t)·u′(t)。§3 の f′ と §11 の g′ はこの 2 つの式から出る。

B　3 次方程式の根の数と解の公式

根の数: 実数の係数の 3 次式 F(s) ＝ s³ ＋ 3p s ＋ q は、s → −∞ で −∞、+∞ で +∞ なので、実根を少なくとも 1 つ持つ。F′(s) ＝ 3s² ＋ 3p なので、

  • p ≥ 0 なら F は単調に増え、実根はちょうど 1 つ。
  • p < 0 なら s ＝ ±√(−p) で極大と極小を持ち、その値は F(±√(−p)) ＝ q ∓ 2(−p)3/2。実根が 3 つになるのは、極大が正・極小が負のとき、つまり 2 つの値の積 q² − 4(−p)³ ＝ q² ＋ 4p³ ＝ h が負のときである。

よって h < 0 ⇔ 異なる実根 3 つ、h > 0 ⇔ 実根 1 つ（残る 2 つは互いに共役な複素数）、h ＝ 0 ⇔ 重根。教科書の判別式 Δ ＝ −4(3p)³ − 27q² とは Δ ＝ −27h の関係で、符号が逆になる。

カルダノの公式で実根 3 つを扱えない理由: h < 0 のとき、§7 の u³, v³ ＝ (−q ± √h)/2 は複素数になる。答えの 3 つの根は実数なのに、公式は複素数の立方根を通らないと書けない（歴史的に「還元不能の場合」と呼ばれる）。§8 の三角関数の解は、複素数の立方根を角度の 1/3 として書き直したものに当たる。

C　3 倍角の公式

加法定理 cos(α ＋ β) ＝ cos α cos β − sin α sin β から、cos 2φ ＝ 2cos²φ − 1、sin 2φ ＝ 2 sin φ cos φ。これを使って

cos 3φ ＝ cos 2φ cos φ − sin 2φ sin φ
　　　＝ (2cos²φ − 1) cos φ − 2 sin²φ cos φ
　　　＝ (2cos²φ − 1) cos φ − 2(1 − cos²φ) cos φ ＝ 4cos³φ − 3cos φ

§8 は、3 次方程式をこの恒等式の形に合わせ込み、「3 倍した角の cos が分かっている」問題に変えている。arccos で 1 つの角が出れば、残りの 2 つは 2π/3 ずつずらした角である。

D　Newton 法と 2 次収束

方程式 g(t) ＝ 0 の根を r、今の近似を t₀ とする。g を t₀ のまわりで 1 次の式（接線）で近似すると g(t) ≈ g(t₀) ＋ g′(t₀)(t − t₀) で、これを 0 にする t が t₁ ＝ t₀ − g(t₀)/g′(t₀) である。

2 次収束: Taylor の定理から、t₀ と r の間のある点 ξ で

0 ＝ g(r) ＝ g(t₀) ＋ g′(t₀)(r − t₀) ＋ ½ g″(ξ)(r − t₀)²

両辺を g′(t₀) で割って t₁ の式と比べると、

t₁ − r ＝ ( g″(ξ) / (2g′(t₀)) ) (t₀ − r)²

つまり新しい誤差は古い誤差の 2 乗に比例する。誤差が 10−3 なら次は 10−6 程度、その次は 10−12 程度で、正しい桁の数が 1 回ごとにおよそ倍になる。この性質は、g′(r) ≠ 0（重根でない）で、t₀ が根に十分近いときに成り立つ。遠い出発点や g′ が 0 に近い所では、行き過ぎたり別の根へ行ったりするので、§11.2 の 2 つの守りを置く。

E　浮動小数点と桁落ち

単精度の浮動小数点数（IEEE 754 binary32）は、符号 1 ビット・指数 8 ビット・仮数 23 ビット（先頭の 1 を含めて 24 桁）で、数を ±1.xxx…(2 進) × 2e の形で持つ。相対的な精度は 2−24 ≈ 6×10−8 で、たとえば 52.8 の近くで表せる隣どうしの数の間隔（ulp）は 2−18 ≈ 3.8×10−6 である。足し算や掛け算の結果は、いちばん近い表せる数に丸められる。

桁落ち（cancellation）: 52.808477 と 52.808464 のように、ほぼ等しい 2 数を引くと、上の桁が打ち消し合い、下の桁——もともと丸めの誤差を含む桁——だけが残る。2 数がそれぞれ ulp の半分ほどの誤差を持てば、差の誤差も ulp ほど（3.8×10−6）で、真の差が 10−7 ならそれは誤差に埋もれる。表 1 では、単精度の √h と q がまったく同じ数に丸められ、差がちょうど 0 になった。

立方根による拡大: ∛x の傾きは x → 0 で無限大になるので、0 の近くの小さな誤差は立方根で大きく引き伸ばされる（∛(3×10−7) ≈ 0.0068）。§10.1 の誤差はこの 2 つが重なったものである。

FMA（fused multiply-add）: GPU は a × b ＋ c を、途中で丸めずに 1 回の丸めで計算する命令を持ち、コンパイラはそれを使うことがある。丸めの回数が変わるので、同じ式でも CPU と GPU で下の桁が違いうる。モデルの「GPU の近似を真似る」計算はこれも真似る。
