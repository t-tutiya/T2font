- 実装が完了した文書は**二択**——①削除せず `docs/archive/completed-designs/` へ**凍結退避**する（要点は `docs/archive/decisions.md` に集約）／②本フォルダに残すなら**冒頭バナーに「本書が現役なのは〜を所有するため」を明記する**。規則の正典は [`../README.md`](../README.md)「ドキュメント運用ルール」（D-DOCLIFE）。
- **下表は対象の 1 行説明だけを持つ**。現役理由・実装状況・裁定の経緯は下表に書かない——現役理由の正典は各文書の冒頭バナー、裁定は `../archive/decisions.md`、完了記録は `../archive/completed-roadmap.md`（D-DOCDUP）。
